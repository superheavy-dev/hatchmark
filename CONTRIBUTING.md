# Contributing to Hatchmark

Hatchmark is open source under the [Apache License 2.0](LICENSE), but it is not open to outside code contributions for now.

## Issues are welcome

Bug reports and feature requests are welcome. Please open a [GitHub issue](https://github.com/superheavy-dev/hatchmark/issues) and include what you expected, what happened, and the smallest spec or steps that reproduce it.

## Pull requests

Source files are TypeScript: `pnpm lint` rejects any tracked `.js`, `.mjs` or `.cjs` file, since Node runs `.ts` files directly.

Pull requests from outside contributors will be closed without review. This is not a judgment of the change; we are not set up to accept outside code yet.

If this policy changes, outside contributions will require signing a Contributor License Agreement (CLA) before they can be merged. This file will be updated when that happens.
